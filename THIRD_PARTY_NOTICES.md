# Third-party components

- [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 5.2.2 — MIT.
- [CTkMessagebox](https://github.com/Akascape/CTkMessagebox) 2.7 by Akash Bora — CC0 1.0 Universal. Used for styled notifications; embedded icons are included in the Windows EXE.\n- [CTkRangeSlider](https://github.com/Akascape/CTkRangeSlider) 0.3 by Akash Bora — CC0 1.0 Universal. The upstream implementation is vendored unchanged in `vendor/CTkRangeSlider/`, together with its original `LICENSE`.
- [PyInstaller](https://pyinstaller.org/en/stable/license.html) — GPL with an exception for distribution of bundled applications.
- [Pillow](https://pillow.readthedocs.io/en/stable/about.html) — HPND.
- [TkinterDnD2](https://github.com/pmgagne/tkinterdnd2) 0.4.3 — MIT wrapper for TkDND, bundled into the Windows executable with its native binaries. Preserve the upstream notices when redistributing.\n- [FFmpeg/FFprobe/FFplay](https://ffmpeg.org/legal.html) — standalone third-party tools. The Windows build pipeline downloads Gyan's release-essentials binaries. GPL/LGPL license obligations vary by build; check the license and source-offer requirements before public redistribution.

AudioCoder's own source is MIT licensed.
