# AudioCoder

Портативный аудиоредактор и конвертер для Windows 10/11 x64 на Python 3.13 и CustomTkinter. Обработка и предпрослушивание используют FFmpeg/FFplay. Проект использует схему версий и релизов [FlacSplitter](https://github.com/medneem/FlacSplitter).

## Возможности

### Открытие и редактирование

- Открытие FLAC, MP3, WAV, APE, AAC/M4A, OGG, Opus, WMA и других форматов, поддерживаемых FFmpeg. FFprobe определяет длительность, кодек, частоту дискретизации и каналы.
- Открытие через кнопку или перенос одного аудиофайла из Проводника Windows на waveform (включая кириллицу и пути с пробелами).
- При запуске **автоматически загружается последний редактируемый файл**, если он существует. Сохранённые границы выделения и масштаб волны восстанавливаются. Если файл удалён/перемещён, об этом сообщает строка состояния, программа продолжает работать.
- Волновая форма высотой 120 px: **левая кнопка** — перемещение ближайшего маркера, **колесо** — масштаб до ×16, **правая кнопка с перетаскиванием** — сдвиг. После масштабирования детальный участок пересчитывается фоновым FFmpeg с задержкой 280 мс; устаревшие результаты отбрасываются.
- **− / +** — изменение масштаба; **Показать выделение** — поместить выделенный фрагмент в окно; **↻ Сброс** — показать весь трек. Отображаются временные границы видимого участка. Тихая волна усиливается только *визуально*, без изменения аудиофайла.

### Прослушивание и навигация

- **▶ Воспроизвести / ■ Остановить** — прослушивание выбранного фрагмента между маркерами через FFplay. При включённых эффектах применяются те же FFmpeg `afade`, что и при экспорте.
- **Повторять фрагмент** — после успешного окончания воспроизведение начинается снова с левого маркера (в том числе при предпрослушивании после его перемещения). Отдельный короткий просмотр справа не повторяется. Повтор реализован новым запуском FFplay, поэтому возможна короткая пауза между циклами.
- При перемещении **левого маркера** воспроизведение идёт от него до правого маркера, с **обоими выбранными эффектами** Fade In и Fade Out. При перемещении **правого маркера** звучит последняя секунда перед ним, только с Fade Out (длительность эффекта сжимается до времени предпрослушивания).
- Предпрослушивание при перетаскивании начинается после паузы 250 мс или сразу после отпускания кнопки мыши. Предыдущее воспроизведение прерывается.
- Навигационные кнопки **сразу запускают звук**, без предварительного нажатия «Воспроизвести»: **|◀** — от левого маркера, **▶|** — последняя секунда перед правым, **−1 с / +1 с** — шаг курсора и воспроизведение с новой позиции. После перехода внутрь выделения Fade In заново не запускается; Fade Out сохраняется у правой границы.

### Независимые Fade In и Fade Out

- Общая галочка **«Плавное появление и затухание»** включает обработку. Для каждой границы независимо задаются **алгоритм** и **длительность**: 0,5 / 1 / 2 / 3 / 5 секунд.
- Алгоритмы: **Нет**, логарифмический, линейный, четверть/половина синусоиды, экспоненциальный, квадратичный, кубический, обратная парабола. «Нет» отключает только соответствующий эффект.
- При смене **алгоритма или длительности появления** сразу прослушивается весь выделенный фрагмент, **включая затухание в конце**. При смене алгоритма или длительности затухания прослушивается последняя секунда перед правым маркером.
- Если сумма выбранных длительностей превышает длину фрагмента, обе длительности пропорционально сокращаются без наложения, сохраняя их соотношение. При отключении одной стороны вторая может занимать всю длину короткого фрагмента.
- Графические направляющие поверх waveform учитывают независимые длительности. Кнопка **❔ Справка** открывает отдельное прокручиваемое окно с описанием и примерами всех кривых.
- Экспорт и прослушивание используют общую логику формирования `afade`; оригинальный файл при предпрослушивании не изменяется.

### Конвертация и настройки

- Форматы результата **FLAC / MP3 / WAV / Opus**, битрейты MP3 и Opus 128/192/256/320 кбит/с.
- **VBR** — отдельная галочка: MP3 использует качество LAME 0–9, Opus — VBR on/off при выбранном целевом битрейте. По умолчанию VBR выключен.
- FLAC compression_level=12 (без потерь), MP3 LAME с compression_level=0, Opus complexity=10, WAV — PCM 24-bit. Перекодирование lossy-формата в FLAC не восстанавливает потерянные данные.
- Фоновая конвертация с прогрессом и отменой. Результат записывается как `<исходное имя>_converted.<формат>` рядом с оригиналом или в выбранной папке. Существующий результат заменяется **только после успешной обработки**, исходный файл никогда не перезаписывается. **По завершении** появляется CTkMessagebox с именем и путём файла: **«Открыть папку»** запускает Проводник Windows с **выделенным готовым файлом**, а **«Хорошо»** только закрывает окно без открытия папки. Закрытие сообщения крестиком также не открывает папку. При отмене или ошибке конвертации Проводник не запускается. Если Проводник недоступен, файл остаётся сохранённым, приложение показывает предупреждение.
- Все настройки сохраняются в переносимом `config.json` рядом с приложением: формат, битрейт/VBR, выбор и **отдельные длительности двух эффектов**, повтор, тема, пути, последний исходный файл, границы маркеров, масштаб и положение waveform.
- **Совместимость со старым config.json:** прежнее поле `fade_seconds` автоматически переносится в `fade_in_seconds` и `fade_out_seconds`, если новые значения ещё не заданы. При следующем сохранении используется новая схема.
- Уведомления об успехе, ошибках и предупреждениях оформлены через [CTkMessagebox](https://github.com/Akascape/CTkMessagebox) 2.7 и согласованы со светлой и тёмной палитрой программы.
- Светлая тема по умолчанию; доступны «Тёмная» и «Системная». Компактное окно без внутренней прокрутки, минимальная высота учитывает масштаб Windows. В левом верхнем углу окна и на панели задач используется **фирменная иконка AudioCoder** (общая с иконкой EXE), а не стандартная CustomTkinter. На Windows заголовок получает настоящий `.ico` через `iconbitmap()` **до** отложенной установки штатной иконки CustomTkinter; в портативный EXE этот `.ico` включён как ресурс.

**Ограничения:** обрезка с декодированием/перекодированием FFmpeg, не побайтовая; обложки и дополнительные дорожки пока не копируются, пакетной конвертации нет. Волновая форма вычисляется в отдельном потоке, её загрузка может занимать время для длинных файлов.

## Разработка (Windows)

Нужен Python 3.13. `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe` должны быть рядом с `main.py` либо в PATH.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-build.txt
python main.py
python -m unittest discover -s tests -v
```

Служебные процессы FFmpeg запускаются без консольных окон. `CTkMessagebox` вместе с иконками входит в PyInstaller EXE. Drag & drop реализован через `tkinterdnd2`; сторонний `CTkRangeSlider 0.3` включён в `vendor/CTkRangeSlider`. Версия CustomTkinter закреплена на 5.2.x из-за совместимости с внутренним API ползунка.

## Архитектура

```text
main.py                          — запуск GUI
audiocoder/
  ui.py                          — CustomTkinter, события, фоновые потоки
  player.py                      — FFplay, предпрослушивание, остановка и курсор
  converter.py                   — FFmpeg, кодеки и безопасная замена результата
  explorer.py                    — открытие Проводника и выделение готового файла
  app_icon.py                    — единый рисунок иконки для GUI и сборки EXE
  fade.py                        — кривые и независимые длительности для FFmpeg
  fade_help.py / fade_preview.py — справка и графики
  settings.py                    — переносимый JSON и миграция старого формата
  selection.py                   — проверка выбранного интервала
  waveform.py                    — извлечение амплитудной огибающей
  waveform_view.py               — быстрый Canvas, маркеры и Fade-направляющие
  waveform_navigation.py        — масштабирование и координаты
  waveform_jobs.py              — последние актуальные задания детального зума
  media.py / drag_drop.py        — FFprobe и Windows drag & drop
  palette.py / ui_style.py       — темы и типографика
vendor/CTkRangeSlider/           — исходники виджета и лицензия
tests/                           — unittest, GUI smoke и FFmpeg integration
scripts/                         — версия и иконка
.github/workflows/build-windows.yml
```

GUI не декодирует аудио в основном потоке. Экспорт сначала пишется во временный файл в целевой папке, затем заменяет результат через `os.replace`. При ошибке/отмене предыдущий результат сохраняется.

## Версии и скачивание

- **Готовые версии скачивайте в [GitHub Releases](https://github.com/medneem/AudioCoder/releases/latest)** — это основная ссылка на ZIP для Windows x64.
- [Список всех релизов](https://github.com/medneem/AudioCoder/releases).
- В исходниках указано `0.1.0-dev`; в GitHub Actions номер сборки становится `0.1.<github.run_number>`.
- PR запускает тесты и проверочную сборку; push в `main` публикует релиз с файлом `AudioCoder-v0.1.N-windows-x64.zip`.
- Архив содержит `AudioCoder.exe`, FFmpeg/FFprobe/FFplay, иконку, VERSION.txt и файлы лицензий.

## Проверка

`python -m unittest discover -s tests -v` проверяет выбор кнопок успешного сообщения («Открыть папку» / «Хорошо») и применение иконки окна (без Проводника при отмене и ошибке), параметры кодеков, логику обоих fade (в том числе разные длительности и короткие фрагменты), предпрослушивание, транспорт, импорт настроек прежней версии, восстановление сеанса, waveform, drag & drop, GUI, ошибки, отмену и реальный прогон FFmpeg. Windows CI выполняет также `compileall`, проверку ошибок обратных вызовов Tkinter, сборку PyInstaller и проверку содержимого ZIP. Проверка фактического звука на аудиоустройстве пользователя выполняется вручную.
