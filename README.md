# AudioCoder

Портативный аудиоконвертер для Windows 10/11 x64 на Python 3.13 + CustomTkinter. Основан по структуре, версионности и релизной схеме на [FlacSplitter](https://github.com/medneem/FlacSplitter).

## Возможности MVP

- Открытие аудиофайла (FLAC, MP3, WAV, APE, AAC/M4A, OGG, Opus и другие форматы, поддерживаемые установленным FFmpeg).
- Определение кодека, длительности, частоты дискретизации и числа каналов через FFprobe.
- **Перетаскивание одного аудиофайла из Проводника Windows прямо на waveform** (FLAC/MP3/WAV/APE/M4A/AAC/OGG/Opus/WMA), включая пути с пробелами и русскими буквами. При неподдерживаемом типе показывается сообщение.\n- **Waveform** с выделенным диапазоном, индикатором позиции воспроизведения, масштабом колесом мыши (до ×16), панорамированием правой кнопкой и точным перемещением границ левой кнопкой по увеличенной волне. При увеличении/сдвиге видимая часть записи **автоматически пересчитывается FFmpeg в высокой детализации** и заполняет всю ширину окна; пока обработка идёт, мгновенно показывается обзорная волна. Пересчёт запускается через 280 мс после остановки колеса/сдвига, устаревшие результаты игнорируются. Возле ×1–×16 теперь показаны **временные границы реально видимого участка**, а график автоматически увеличивает слабую амплитуду по высоте для разборчивости (только на экране, исходный звук не изменяется). Сброс масштаба отдельной кнопкой. CTkRangeSlider остаётся доступен под волной.
- Кнопка **▶ Воспроизвести / ■ Остановить** прослушивает весь выбранный диапазон **с включённым появлением и затуханием** — FFplay применяет те же фильтры `afade`, что и FFmpeg при экспорте. Если общая галочка выключена, прослушивание идёт без эффектов.
- Галочка **«Повторять фрагмент»**: после успешного завершения FFplay воспроизведение всего выделения (в том числе начатое перетаскиванием левого маркера) начинается заново от левой точки. Предпрослушивание правого маркера не зацикливается. Настройка запоминается в `config.json`.
- При переключении **кривой появления** автоматически прослушивается весь фрагмент от левого до правого маркера, при переключении **кривой затухания** — последняя секунда до правого маркера. Существующее прослушивание заменяется новым, исходный файл не меняется.
- Панель навигации **сразу запускает звук**: **|◀** — воспроизведение от левого маркера, **▶|** — последняя секунда перед правым маркером, **−1 с / +1 с** — шаг курсора по выделению с воспроизведением от новой позиции. При ручном позиционировании сохраняется затухание у исходной правой границы.
- Дополнительные кнопки масштаба **− / + / Показать выделение**; прежняя **↻ Сброс** по-прежнему показывает весь трек.
- Перемещение **левого** маркера: воспроизведение **от левой точки до правой границы** (если правый маркер стоит в конце файла, до конца трека). При включённом повторе звучит циклически.
- Перемещение **правого** маркера: предпрослушивание последней **1 секунды перед правой точкой**, ограниченное левой границей.
- Предпрослушивание при перетаскивании запускается после паузы 250 мс или сразу при отпускании ползунка. Предыдущее воспроизведение останавливается. Левый маркер воспроизводит только выбранное появление, правый — только затухание; эффект при необходимости сокращается до длины короткого предпрослушивания.
- Оформление параметров по утверждённому третьему макету: отдельные карточки формата/битрейта, выделенная голубая панель fade-in/out и строка папки. Единый шрифт Segoe UI 13 для элементов и увеличенный заголовок.
- В шапке справа только **Справка** и выбор темы (версия остаётся в заголовке окна). Waveform имеет сглаженные скруглённые углы, совпадающие с фоном основной карточки. Удалена строка «Результат: …» под папкой; отступы после строки папки компактные и симметричные.\n- Светлая тема по умолчанию; переключатель «Светлая / Тёмная / Системная» в верхней панели.\n- **Светлые второстепенные кнопки и поля выбора** в светлой теме: тёмные подписи, непрерывные 2-пиксельные рамки с уменьшенным скруглением и мягкие состояния наведения. «Конвертировать» — единственная более выраженная кнопка; «Отмена» — нейтральная. Тёмная тема использует соответствующие светлые подписи. Цвета waveform и карточек остаются спокойными. Пользовательские настройки и обработка аудио не меняются. Палитра хранится в `audiocoder/palette.py` и `audiocoder/themes/quiet_slate.json` (включены в Windows EXE).
- **Убрана общая серая подложка редактора:** содержимое располагается на фоне самого окна, без лишней внешней заливки и горизонтальных полей. Карточки масштаба, формата, затухания и папки используют одинаковый белый цвет в светлой теме и единый тёмный фон в тёмной; границы одинаковые, ровные и сплошные.\n- **Компактное главное окно без внутренней прокрутки**: уменьшены вертикальные отступы, waveform высотой 120 px, кнопка открытия файла перенесена в строку заголовка аудиофайла, а статус, прогресс и кнопки воспроизведения/конвертации остаются внизу. Минимальная высота автоматически определяется по элементам и масштабу Windows, чтобы настройки не обрезались.
- Конвертация в **FLAC / MP3 / WAV / Opus**. MP3 и Opus 128/192/256/320 кбит/с. **VBR — отдельная галочка**; для MP3 включается режим качества LAME 0–9 (0 — лучшее), а битрейт в VBR-режиме не ограничивает поток; для Opus VBR on/off при выбранном целевом битрейте. По умолчанию VBR выключен.
- Качественное кодирование: FLAC compression_level=12 (lossless), MP3 CBR/VBR с LAME compression_level=0, Opus CBR/VBR complexity=10, WAV PCM 24-bit. Сжатие **не восстанавливает** информацию из MP3 и других lossy-источников.
- По желанию включаются **появление и затухание** через FFmpeg `afade`: для каждой границы выбирается свой алгоритм (**первый пункт «Нет»**, логарифмический, линейный, четверть/половина синуса, экспоненциальный, квадратичный, кубический, обратная парабола). «Нет» независимо выключает эффект на левой или правой границе; значение сохраняется в `config.json`. Длительность общая 0.5/1/2/3/5 с; короткие фрагменты автоматически ограничивают эффект. **Большие графики убраны из главного окна.** Кнопка **❔ Справка** открывает отдельное прокручиваемое окно: все 8 алгоритмов с описанием, двумя сглаженными иллюстрациями появления/затухания, осями, сеткой и шкалой громкости. На графиках условный 1-секундный пример (0–0.2 с и 0.8–1 с), реальная длительность задаётся в главном окне. На waveform по-прежнему отображается выбранный fade.
- Фоновая обработка (интерфейс не блокируется), прогресс, отмена.
- Имя результата: `<исходное имя>_converted.<формат>` в исходной или выбранной папке.
- Исходные файлы не изменяются; **существующий выходной файл заменяется** при успешной конвертации. При ошибке/отмене предыдущий результат остаётся цел.
- **При запуске автоматически открывается последний редактируемый аудиофайл**, если он ещё доступен. Если файла нет, приложение открывается без файла и сообщает об этом в строке состояния. **Все изменяемые настройки** сохраняются в `config.json` рядом с исходниками/EXE (UTF-8): формат, битрейт, VBR, VBR-качество, алгоритмы/duration фейдов, состояние эффекта, оформление, папки, последнее имя исходного файла, начальная/конечная позиции маркеров и масштаб/сдвиг waveform. При повторном открытии того же файла диапазон и масштаб восстанавливаются. Во время перетаскивания сохранение откладывается на 600 мс, чтобы не нагружать интерфейс.

**Важно:** обрезка использует декодирование/перекодирование FFmpeg, а не побайтовое копирование. Lossless-источник в FLAC/WAV сохраняет аудио без потерь, MP3/Opus — с потерями. WAV экспортируется как PCM 24-bit. Обложки и дополнительные дорожки в MVP не копируются. Пакетная конвертация пока не реализована. Waveform строится через FFmpeg (4096 отсчётов) на отдельном потоке после анализа FFprobe; во время подготовки волны выбор диапазона и конвертация доступны. Для длительных файлов возможна задержка перед отрисовкой waveform.

## Разработка (Windows)

Требуется Python 3.13. **FFmpeg, FFprobe и FFplay** должны находиться возле `main.py` либо в PATH. FFplay использует звуковое устройство Windows; на беззвучном CI реальный вывод звука не тестируется.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-build.txt
python main.py
python -m unittest discover -s tests -v
```

На Windows служебные процессы FFprobe, FFmpeg и FFplay запускаются без консольных окон. Для drag & drop используется `tkinterdnd2` с включёнными TkDND-библиотеками в PyInstaller.\n\nCTkRangeSlider 0.3 включён как исходный код в `vendor/CTkRangeSlider`. Он использует внутренний API CustomTkinter 5.2.x, поэтому версия CustomTkinter зафиксирована. Новую 6.x необходимо отдельно проверить на совместимость.

## Архитектура

```text
main.py                        — запуск GUI
audiocoder/
  ui.py                        — CustomTkinter UI, события, фоновые worker threads
  selection.py                 — выбор и проверка диапазона
  media.py                     — FFprobe, метаданные и поиск инструментов\n  drag_drop.py                 — безопасный разбор Windows TkDND списка файлов\n  ui_style.py                  — единая типографика интерфейса
  converter.py                 — FFmpeg и атомарная замена существующего результата
  player.py                    — фоновое FFplay-воспроизведение, режимы предпрослушивания и отмена
  waveform.py                  — извлечение амплитудной огибающей FFmpeg showwavespic
  waveform_view.py             — быстрый raster Canvas, zoom/pan, edit и курсор воспроизведения\n  fade.py                      — точные функции громкости FFmpeg для выбранных алгоритмов\n  fade_preview.py              — сглаженные графики огибающих с осями и сеткой
  fade_help.py                 — отдельная прокручиваемая справка с примерами всех кривых\n  waveform_navigation.py       — координаты, границы viewport и точный масштаб
  waveform_jobs.py             — один фоновый декодер и последний актуальный запрос зума
  settings.py                  — переносимые настройки JSON
vendor/CTkRangeSlider/         — неизменённые upstream исходники виджета + лицензия
tests/                         — unittest (логика, GUI smoke, FFmpeg integration)
scripts/stamp_version.py       — version.py и Windows VERSIONINFO
scripts/build_icon.py          — генерация PNG / Windows ICO
.github/workflows/build-windows.yml
```

GUI не вызывает FFmpeg в основном потоке. Файлы-результаты сначала создаются под случайным временным именем в целевой папке. После успешного завершения временный файл **атомарно заменяет** существующий результат (`os.replace` на той же файловой системе). Если конвертация не удалась или была отменена, старый результат не затрагивается. Исходный файл не заменяется никогда.

## Версии и релизы

- В исходниках: `0.1.0-dev`.
- GitHub Actions на каждом запуске выставляет `0.1.<github.run_number>` и штампует Windows VERSIONINFO.
- В PR: запускаются тесты и собирается ZIP-артефакт.
- При push в `main`: после успешной сборки автоматически создаются тег `v0.1.N` и GitHub Release с `AudioCoder-v0.1.N-windows-x64.zip`.
- Архив содержит `AudioCoder.exe`, `ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe`, иконку, `VERSION.txt` и тексты лицензий.

## Тесты

`python -m unittest discover -s tests -v`: покрыты VBR и CBR аргументы кодеков, режимы предпрослушивания, все варианты фейдов, справку и графики, drag & drop и скрытый FFprobe, сохранение настроек/диапазона/масштаба, границы фрагментов, формирование CLI аргументов, ошибки, безопасная замена результата, отмена, JSON-конфиг/формат/битрейт/затухание, FFprobe, FFplay (с моками), границы предпрослушивания, waveform, GUI smoke и реальная конвертация короткого тестового сигнала через FFmpeg. Интеграционный тест пропускается, если FFmpeg/FFprobe недоступны. Windows CI устанавливает FFmpeg/FFprobe/FFplay перед тестами. Проверка CI также отслеживает необработанные ошибки Tkinter, даже если процесс unittest завершился успешно. В тестах убраны дублирующие сценарии старой компоновки и настроек, сохранены регрессионные проверки функций. Проверка реального вывода звука на устройстве пользователя выполняется вручную.
